# 🌀 Fract-ol - Proyecto de la Escuela 42

Fract-ol es un proyecto gráfico de la escuela 42 que consiste en renderizar fractales complejos utilizando la biblioteca gráfica **MiniLibX**. El objetivo es explorar el mundo de los números complejos y la recursividad, mientras se desarrolla una interfaz gráfica simple y se gana experiencia con el manejo de eventos y visualización en tiempo real.

---

## 🧠 Objetivos del Proyecto

- Aprender a trabajar con gráficos mediante **MiniLibX**.
- Manipular números complejos para generar fractales.
- Implementar interacción con teclado y ratón.
- Optimizar el código para lograr una renderización fluida.
- Comprender la lógica detrás de fractales como Mandelbrot, Julia, y otros.

---

## 🔮 Fractales Implementados

- 🌌 **Mandelbrot**
- 🧬 **Julia**

---

## ⚙️ Requisitos

- Sistema Unix (preferiblemente macOS o Linux).
- Bibliotecas instaladas:
  - `MiniLibX`
  - `X11` (Linux) o frameworks de gráficos en macOS.
- Compilador `cc`.
